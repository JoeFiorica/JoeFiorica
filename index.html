    A Python tool for safely normalizing MMDD-based filenames. Unique dates stay unchanged; duplicates are reassigned to the nearest free date using ±offset search. Protects thumbnail companions and guarantees collision-free renaming across large media folders.

  • timestamp-filename-normalizer↗

    A Python tool that normalizes MP4 filenames by extracting datestamps from legacy formats or from each video’s associated raw data folder. Supports wildcard matching, validates naming against a consistent SYYYYEMMDD – Title.mp4 standard, and ensures clean, sortable, chronologically accurate media libraries.
